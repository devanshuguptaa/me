# Devanshu Gupta — Portfolio

A personal portfolio showcasing engineering work across AI systems, machine learning, document intelligence, and full-stack software.

## Stack

- Next.js App Router
- TypeScript
- React
- Custom CSS

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deployment

This repository is connected to Vercel. Pushes to the production branch trigger deployments.
